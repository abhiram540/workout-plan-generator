# 🏋️‍♀️ Workout Plan Generator 🏋️

A Streamlit app that turns a few structured questions about your goals, schedule, equipment, and limitations into a personalized, coach-quality weekly workout plan — generated by an LLM via the [Groq API](https://groq.com/).

**🔗 Live app:** [workout-plan-generator-by-abhiram.streamlit.app](https://workout-plan-generator-by-abhiram.streamlit.app/)

---

## What it does

Most "AI workout generator" demos just concatenate form inputs into a sentence and hope for the best. This one is built like a real intake form a personal trainer would use:

- **Structured inputs, not a text box** — fitness goal, experience level, days available per week, equipment access, and optional injuries/limitations.
- **A prompt designed to respect constraints** — the plan always has exactly as many training days as requested, only uses exercises available with your stated equipment, and explicitly works around any reported injuries instead of ignoring them.
- **Structured output** — a day-by-day breakdown with warm-ups, exercise tables (sets/reps/rest), and weekly notes, not a wall of text.
- **Scoped and safe** — no medical claims, and an automatic disclaimer when injury-related input is given.
- **Resilient by design** — invalid inputs, failed API calls, and empty/malformed responses all fail gracefully with a friendly message instead of crashing the app.

### Extras

- 🔄 **Regenerate** — get a different variation of the same plan.
- 💾 **Download** — save the plan as a `.md` file.
- 🔁 **Swap an exercise** — ask for a single safe alternative to any exercise in the plan.
- Plan persists across reruns via `st.session_state`.

## Tech stack

- **Python** — typed functions (`workout_generator.py`), all API calls wrapped in `try/except`
- **[Streamlit](https://streamlit.io/)** — UI, with a custom dark, energetic theme (`.streamlit/config.toml`)
- **[Groq](https://groq.com/)** — LLM inference (`openai/gpt-oss-120b` by default)

## Running it locally

1. **Clone the repo**

   ```bash
   git clone https://github.com/abhiram540/workout-plan-generator.git
   cd workout-plan-generator
   ```

2. **Install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

3. **Add your Groq API key**

   Copy `.env.example` to `.env` and paste in your key (get one free at [console.groq.com](https://console.groq.com/)):

   ```
   GROQ_API_KEY=your_key_here
   ```

4. **Run the app**

   ```bash
   streamlit run app.py
   ```

   If no key is found in `.env`, the app will let you paste one directly in the UI for that session.

## Deploying your own copy

This app is deployed on [Streamlit Community Cloud](https://streamlit.io/cloud). To deploy your own:

1. Push this repo to your own GitHub account.
2. On Streamlit Cloud, create a new app pointing at your repo, branch `master`, and main file `app.py`.
3. Under **Advanced settings → Secrets**, add:

   ```toml
   GROQ_API_KEY = "your_key_here"
   ```

No code changes needed — the app checks `st.secrets` automatically.
